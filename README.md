# FocusFlow — Interactive Task Tracker

A simple task tracker made with HTML, CSS and JavaScript.

## Files
- `Webproject1.html` — webpage structure
- `creative.css` — styling and responsive layout
- `functional.js` — task tracker functionality

## Features
- Add and delete tasks
- Mark tasks as completed
- Filter all, active and completed tasks
- View task counts and completion progress
- Save tasks in the browser using localStorage

## Run
Open `Webproject1.html` in a web browser. No installation is required.
